# Retail Sales Data Analysis using Excel

## Project Overview

This project focuses on analyzing a retail sales dataset containing 999 transaction records using Microsoft Excel. The objective was to perform data cleaning, apply spreadsheet functions, create pivot tables, and visualize business insights through charts.

## Tools Used

* Microsoft Excel
* Pivot Tables
* IF Function
* SUMIF Function
* VLOOKUP Function
* Charts and Data Visualization

## Dataset Information

The dataset consists of retail transaction records with the following attributes:

* Transaction ID
* Date
* Customer ID
* Gender
* Age
* Product Category
* Quantity Purchased
* Price per Unit
* Total Amount

## Data Analysis Performed

### 1. Data Cleaning

* Verified dataset structure and formatting.
* Checked for missing or inconsistent values.
* Formatted date fields correctly.
* Organized data into Excel tables for efficient analysis.

### 2. Spreadsheet Functions

* Used IF function to classify purchases as High Value and Low Value transactions.
* Applied SUMIF to calculate category-wise sales totals.
* Demonstrated VLOOKUP for retrieving related information from lookup tables.

### 3. Pivot Table Analysis

Created multiple pivot tables to summarize and analyze sales performance across different dimensions:

* Product Category Analysis
* Gender-wise Sales Analysis
* Age Group-wise Sales Analysis

## Key Findings

### Product Category Performance

| Category    | Total Sales |
| ----------- | ----------- |
| Electronics | 156,905     |
| Clothing    | 155,580     |
| Beauty      | 143,515     |

#### Insights

* Electronics generated the highest revenue among all product categories.
* Clothing closely followed Electronics, indicating strong customer demand.
* Beauty products contributed the lowest sales revenue but still represented a significant portion of overall sales.
* The small difference between Electronics and Clothing sales suggests balanced consumer spending across these categories.

### Gender-wise Sales Analysis

| Gender | Total Sales |
| ------ | ----------- |
| Female | 232,840     |
| Male   | 223,160     |

#### Insights

* Female customers generated the highest total revenue.
* Female customers spent 9,680 more than male customers.
* Sales contributions from both genders were relatively balanced, indicating broad customer engagement.
* Marketing campaigns targeted toward female customers may yield additional revenue opportunities.

### Age Group Analysis

#### Insights

* Purchasing behavior varies across different age groups.
* Certain age groups contribute more significantly to overall revenue, indicating valuable customer segments.
* Age-based analysis can help businesses design targeted marketing strategies and personalized promotions.
* Understanding age-wise spending patterns can improve customer retention and product positioning.

## Business Recommendations

1. Increase inventory and promotional efforts for Electronics products, as they generate the highest revenue.
2. Maintain strong focus on Clothing products due to their consistent sales performance.
3. Develop targeted campaigns for female customers, who contribute slightly higher revenue.
4. Use age-group insights to create personalized marketing strategies.
5. Continue monitoring category performance to identify future growth opportunities.

## Conclusion

This project demonstrates the practical use of Excel for data cleaning, analysis, visualization, and business decision-making. Through spreadsheet functions, pivot tables, and charts, meaningful insights were extracted from retail transaction data, helping identify customer behavior patterns and product performance trends.
